# Building Care Enterprises

Static, bilingual (English + Nepali) marketing site for Building Care Enterprises — a hardware, sanitary, electrical, motor vehicle spare parts, furniture, and electronics supplier in Hetauda, Makawanpur, Nepal. Built with Next.js (`output: "export"`) and deployed to GitHub Pages at [buildingcare.com.np](https://buildingcare.com.np).

## Getting started

```sh
npm install
npm run dev      # http://localhost:3000
npm run build    # static export -> out/
npm run preview  # serve out/ locally, as it will actually be hosted
npm run lint
```
