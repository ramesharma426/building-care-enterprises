## Project summary

Static (fully pre-rendered, no Node server) Next.js site for **Building Care Enterprises**, a hardware/sanitary/electrical/motor-parts/furniture/electronics trading shop in Hetauda, Makawanpur, Nepal. Bilingual: English at the unprefixed root, Nepali under `/ne`. Deployed to GitHub Pages at `buildingcare.com.np`. Product catalog is not final yet — see [content-editing.md](./content-editing.md) for how the placeholder category system is meant to be replaced.
